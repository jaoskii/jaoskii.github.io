# jaoskii.github.io

Portfolio of Rajhi John Tabora, full stack developer. Live at https://jaoskii.github.io.

Static site, no build step:

- `index.html`: home (about, experience, stack, side projects, contact)
- `work.html`: case-study slider
- `assets/`: project data (`projects.js`, `inventee.js`, `side.js`, `nda.js`), scripts, styles, images and the CV PDF

Preview locally with any static server, e.g. `python3 -m http.server`.
Pushing to `master` deploys to GitHub Pages through `.github/workflows/deploy.yml`.
